# Контекст проекта: KHL Manager (Хоккейный симулятор)

## 1. Стек и архитектура
- **Язык:** Python (ООП подход, строгая типизация).
- **Интерфейс:** Планируется PySide6 (файлы `ui.py`, `main.py`).
- **База данных:** SQLite (`khl_manager.db`) с использованием связки `conn` (соединение) и `cursor` (управление запросами).
- **Организация кода:** 
  - `models.py` — доменные классы (`Team`, `Conference`).
  - `database.py` — слой сохранения и загрузки (`init_db`, `save_team`, `load_conference`).

## 2. Реализованный функционал
- **Класс Team (`models.py`):** Содержит атрибуты имени, силы (атака, защита, большинство, меньшинство), а также игровую статистику (`points`, `goals_for`, `goals_against`, `matches_played`). Метод `results_of_game()` обновляет очки и стату с учетом правил КХЛ (победы и овертаймы).
- **Класс Conference (`models.py`):** Контейнер для хранения списка команд (`teams`).
- **Модуль базы данных (`database.py`):**
  - `init_db()` — создает таблицу `teams` с уникальными полями и автоинкрементом.
  - `save_team(team, conf_name)` — сохраняет объект в SQLite с защитой от дубликатов через `UPSERT` (`ON CONFLICT(name) DO UPDATE`).
  - `load_conference(conf_name)` — загружает данные из базы и десериализует их обратно в объекты ООП (`Conference` и `Team`).
